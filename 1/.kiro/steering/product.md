# Product

"我的导航" (My Navigation) is a personal website navigation page. Users can browse curated links organized by category, search for sites, and manage their own bookmarks.

## Core Features
- Browse websites grouped by category (学习, 开发工具, 娱乐, AI工具, 工具)
- Search across all sites
- Add, edit, and delete website entries
- User registration and login (JWT-based auth)
- AI-powered website recommendations via Alibaba DashScope (Qwen model)

## Target Users
Chinese-speaking developers and general users who want a self-hosted browser start page.

## Access
Default URL: http://localhost:5000 (served by Flask, which also hosts the built frontend)
